# Bài tập Kotlin cơ bản - Quản lý sinh viên

## Nội dung
Chương trình quản lý sinh viên bằng Kotlin.

Mỗi sinh viên gồm:
- Student ID
- Full Name
- Age
- Major
- GPA

## Chức năng
- Add student
- Display all students
- Search student
- Calculate average GPA
- Find student with highest GPA
- Remove student
- Count students GPA >= 8.0
- Count students GPA < 5.0
- Calculate average GPA by major
- Find oldest student
- Find students with GPA from 7.0 to 8.5
- Find all students by major
- Search student by partial name
- Sort students by GPA descending
- Display top 3 students with highest GPA
- Sort students by age
- Sort students by name

## Công nghệ
- Kotlin
- Android Studio
- Git
- GitHub
